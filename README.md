# Astro (Android)
1. Make a new empty GitHub repo and upload everything in this folder (keep the .github folder).
2. Open the repo's Actions tab, run "Build APK", wait about 5 minutes.
3. Open the finished run, download "astro-apk", unzip, and send app-debug.apk to your phone.
4. Install it (allow "install unknown apps"), open Astro, paste your Gemini key in Settings.
